Agent Architecture Comparison

Cline Subagents vs Claude Code Subagents

So sánh chi tiết giữa ClineSubAgent theo tài liệu Cline và Subagent của Claude Code, tập trung vào mục tiêu thiết kế, quyền hạn, khả năng tùy biến, cách kích hoạt và trường hợp sử dụng thực tế.

Cline Subagents

Thiên về parallel research: nhiều agent đọc hiểu codebase song song, giữ main context sạch, rồi trả về report cho main agent.

Claude Code Subagents

Thiên về specialized delegated assistants: agent chuyên môn có prompt, tool, model, permission và memory riêng, có thể được Claude tự động gọi khi phù hợp.

Tóm tắt nhanh

Tiêu chí Cline Subagents Claude Code Subagents
Bản chất Agent nghiên cứu song song, độc lập, thường dùng để khám phá codebase. AI assistant chuyên môn hóa cho workflow/task cụ thể.
Mục tiêu chính Tăng tốc thu thập context rộng mà không làm phình main context. Tái sử dụng năng lực chuyên biệt, kiểm soát tool/model/permission, giảm nhiễu context.
Cách kích hoạt Cần bật feature Subagents; Cline không tự quyết định hoàn toàn, user nên yêu cầu dùng subagents. Claude có thể tự delegate khi task match description; cũng có thể gọi rõ agent mong muốn.
Quyền công cụ Read-only: đọc file, list/search, list code definitions, chạy command read-only, dùng skills. Có thể read-only hoặc full tools tùy agent; built-in Explore/Plan read-only, general-purpose có all tools.
Khả năng sửa file Không. Bị giới hạn để nghiên cứu, không edit/apply patch. Có thể có, nếu subagent được cấp Write/Edit hoặc dùng general-purpose.
Parallelism Là điểm nhấn chính: nhiều research agents chạy đồng thời. Không chỉ là parallel research; thiên về delegation chuyên môn trong cùng session. Nếu cần nhiều agent giao tiếp song song, Claude Code hướng sang Agent Teams.
Tùy biến Prompt theo từng lần dùng; ít nhấn mạnh cấu hình agent bền vững. Rất mạnh: file Markdown/YAML, description, prompt, tools, model, permissionMode, hooks, skills, memory, maxTurns, isolation, color...
Độ trưởng thành Experimental feature. Là một phần hệ thống Claude Code với built-in agents, project/user/plugin/managed scopes.

Cline Subagents: cách hiểu đúng

Cline Subagents giống một nhóm “trinh sát codebase”. Main agent giao nhiều câu hỏi nghiên cứu nhỏ, mỗi subagent chạy trong context riêng, đọc/search code độc lập, sau đó trả về report cô đọng.

  • Phù hợp khi cần map nhanh nhiều vùng code: auth, API routes, database models, deployment config...
  • Giữ main context không bị ngập bởi log, grep output, file contents.
  • Subagent bị khóa read-only để giảm rủi ro.
  • Không dùng browser, không MCP, không web search, không spawn subagent lồng nhau.

Claude Code Subagents: cách hiểu đúng

Claude Code Subagents giống “nhân sự chuyên trách” trong hệ sinh thái Claude Code. Mỗi agent có mô tả, system prompt, model, tool access và permission riêng, có thể được tái sử dụng xuyên project hoặc chỉ trong project hiện tại.

  • Có built-in agents như Explore, Plan, general-purpose.
  • Có thể tạo custom agent qua /agents hoặc file Markdown trong .claude/agents/ và ~/.claude/agents/.
  • Có thể dùng model rẻ/nhanh hơn cho task phụ.
  • Có thể cấp hoặc hạn chế quyền sửa file tùy mục đích.

Khác biệt cốt lõi

1. Research pool vs agent library

Cline thiên về “pool các agent nghiên cứu tạm thời”. Claude Code thiên về “thư viện agent chuyên môn có cấu hình bền vững”.

2. An toàn mặc định

Cline khóa read-only. Claude Code linh hoạt hơn: có agent read-only, nhưng cũng có agent được phép hành động/sửa code.

3. Cơ chế gọi

Cline thường cần user gợi ý “use subagents”. Claude Code có thể tự chọn agent dựa trên description nếu task phù hợp.

4. Độ tùy biến

Claude Code vượt trội nếu muốn định nghĩa BA agent, reviewer agent, debugger agent, migration agent... dùng lại lâu dài.

Khi nào chọn cái nào?

Chọn Cline Subagents nếu...

  • Bạn đang onboarding codebase lớn.
  • Bạn cần nhiều luồng điều tra độc lập chạy song song.
  • Bạn chỉ muốn research, không muốn agent nào đụng vào code.
  • Bạn muốn report các file quan trọng để main agent đọc tiếp.

Chọn Claude Code Subagents nếu...

  • Bạn muốn tạo agent chuyên môn dùng đi dùng lại.
  • Bạn cần kiểm soát model, tool, permission, memory.
  • Bạn muốn agent có thể vừa nghiên cứu vừa hành động khi được phép.
  • Bạn có workflow lặp lại như review code, debug test, viết PRD/SRS, audit security.

Kết luận ngắn gọn

Cline Subagents là công cụ rất hợp để “chia quân đi đọc code” — nhanh, an toàn, song song, read-only.

Claude Code Subagents là một cơ chế agent hóa workflow mạnh hơn — có thể tạo nhân sự AI chuyên môn, tái sử dụng, cấu hình sâu, và tùy quyền từ read-only đến full-action.
